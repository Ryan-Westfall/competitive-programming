# Competitive Programming

My competitive programming solutions database.

## How It Works

1. **LeetSync Chrome extension** uploads accepted solutions from LeetCode to `leetcode/` directory
2. **GitHub Action** automatically regenerates the index files in `data/` when new problems are pushed
3. **Portfolio website** at [ryan-westfall.info/archive](https://ryan-westfall.info/archive) displays the solutions

## Repository Structure

```
leetcode/          # Individual problem folders (auto-generated by extension)
  └── <id>-<slug>/
      ├── metadata.json    # Problem metadata
      ├── solution.py      # Accepted solution code
      ├── README.md        # Problem description
      └── notes.md         # Personal notes (optional)

data/              # Index files (auto-generated by GitHub Action)
  ├── problems.json  # List of all solved problems
  ├── tags.json      # Tag counts for filtering
  └── stats.json     # Problem statistics

.github/workflows/ # GitHub Actions configuration
  └── generate-archive.yml  # Auto-regenerates data/*.json on push
```

## GitHub Action

The `Generate Archive` workflow runs automatically when new problems are pushed to `leetcode/`. It:
- Scans all `leetcode/*/metadata.json` files
- Generates aggregated JSON files in `data/`
- Commits and pushes the updated index files

No manual intervention required — just push new solutions via the extension.
